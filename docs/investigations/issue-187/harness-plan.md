# Planned local harness and evidence boundary

This is a preimplementation plan. The literal design is awaiting independent review and
main-task clearance; no new constructor or geometry test may execute before both are recorded.

## Private modules

- Each material state has its own frozen constructor under a stage directory. The first state
  implements the exact reviewed anchor, index and displacement table. Its `buildCoast` receives
  the existing bounded anatomy and variation values; it does not initialize a random stream.
- A shared evaluator enumerates the three exact quota expressions in the design, five anatomies
  and four variations. It stitches the fixed roles, applies one uniform area fit to every
  coordinate-valued witness, and calls the frozen issue 178 certificate with the original quota
  value. It does not recover that quota through a different arithmetic association.
- A plain local renderer produces the central-anatomy, variation-zero three-quota panel at
  900 by 320, plus a 450 by 160 counterpart using the same chart extent. The latter samples
  the corresponding even-coordinate pixels of the native mask. Both display unlabelled land
  and water with the established palette; no overlays, noise, islands or world projection.
- Capture/replay orchestration remains separate from the constructor and evaluator. Importing
  that orchestration must not construct a prototype. Geometry is loaded only after the capture
  or replay source checks have passed.

## Capture before execution

Allow only the two declared stage identifiers. Resolve each to a fixed repository-relative
constructor entry, with no user-selected arbitrary import path. Traverse and capture its exact
static dependency closure, the evaluator/renderer/runner, applicable frozen helpers, the literal
stage design, package/lock and tool versions before importing the new constructor.

Create a new stage directory exclusively; reject an existing directory. Write source text and
its manifest before first geometry execution. Execute all 60 cases, retaining failures as well
as successes. Preserve a partial capture if an unexpected runtime failure interrupts execution;
never overwrite or silently restart it under the same identity. Any recovery requires a clearly
documented distinction between a harness failure and changed geometry, with the earlier capture
preserved.

Each successful run records exact inputs, quota, raw/fitted geometry, scale, complete certificate,
failure list and the two image files. Run the same frozen state again and compare all receipts
and image bytes before writing the completion receipt. Check source stability after evaluation.
Deterministic repeats are repetitions of a captured state, not opportunities to alter its shape.

## Trusted read-only replay

The verifier first checks the exact file inventory and schema, fixed entry identity and complete
captured source inventory/text against the corresponding trusted current stage and shared frozen
closure. A coherently rehashed injected source must fail this comparison before any geometry
import. Self-reported hashes do not authorize execution.

After those checks, execute only the trusted matching stage closure, compare artifact hashes and
exact recomputed receipt/image bytes, and verify that source did not change. Fail closed on a
missing, extra, drifted or untrusted source or artifact. A later stage does not rewrite an earlier
constructor or reinterpret its receipts.

## Focused checks and disposition

After the initial captured execution, focused tests verify literal coordinate/index identity,
bounded anatomy/variation rejection, input preservation, single uniform fit and quota semantics,
honest failed certificates and replay source/artifact tampering. Test fixtures may inspect the
same fixed central/corner cases; they must not introduce an exploratory geometry scan.

An independent reviewer inspects the implementation and exact local panel at both sizes. A
passing certificate with opposing jaws, repeated slot geometry or missing readable hierarchy is
a rejected local result. If a second complete state is justified, author and review it before
execution and use the identical 60-case and image gates. No broader work follows automatically
from a local pass. The final disposition separates measured local feasibility, assistant visual
judgment, whole-family/placement limitations and pending human acceptance.
