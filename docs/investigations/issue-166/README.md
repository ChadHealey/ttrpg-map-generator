within separated spherical envelopes**: what minimum interior width, lobe contribution, peninsula
attachment width, embayment depth/opening, and guard clearance count as the intended construction
targets, and which control combinations may terminate with no proposal when those targets cannot fit.

substitutes for human acceptance. Retained scalar quotas and ellipse dimensions do not determine
these choices. No numeric thresholds are endorsed here.
