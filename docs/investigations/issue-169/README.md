## Meaning of evidence

A computed certificate establishes the implemented conservative continuous geometry predicates
with documented floating-point residuals. It is not a formal machine interval proof. Coverage is
independently measured at preview/full anchors using spherical row weights and unchanged tolerances.
The seam/pole/nesting helper checks alias equality and retained anchors; it does not prove topology,
quantized feature survival, ocean connectivity, or polar control semantics. The six retained inputs
all use neutral polar character. Those production responsibilities remain unverified.

A comparison row is numerically eligible only within that limited investigation scope. The unchanged
visual contract still requires all four ordinary rows to pass and both controls to be interpretable.
Assistant review cannot manufacture the human decisions. Accepted v1/v2 data, production schemas,
new-atlas defaults and registered canonical fixtures remain untouched.
