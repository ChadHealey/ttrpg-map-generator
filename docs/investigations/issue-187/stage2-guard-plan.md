# Separate second-stage prerequisite guard

The frozen first-state writer and source helper remain unchanged. The new `stage2.mjs` is the
only proposed authoritative second-state capture/replay entry. It has not recorded a second
state. Independent review and main-task clearance must precede use.

The guard requires fixed paths for a complete second literal design, its independent review,
an immutable copy of the first-state diagnosis, the independent first-state review, and the
completed first-state manifest/receipt/summary. A separate authorization JSON binds all those
bytes and the guard's own source hash. It explicitly declares the first local R3 rejection and
assistant design clearance for the fixed 60-case experiment. Missing files, incomplete predecessor,
changed design/review bytes, unknown fields or a different declared outcome fail before the new
geometry graph is loaded.

The guard also runs the existing first-state read-only verifier before second-state geometry.
This validates all first artifacts and source, rather than trusting only a completion flag.
It captures its own source, all prerequisite text, the exact new layout/evaluator dependency
closure and corpus before the first second-state geometry import. Shared source is still the
frozen first-state implementation. A second-state manifest/receipt uses a distinct guard revision,
so output written through the historical unguarded `run.mjs state-2` path cannot pass this verifier.
That historical argument remains present solely because changing it would rewrite captured source.

The proposed fixed prerequisite paths are:

- `states/state-2/design.md` and `independent-design-review-state2.md`;
- `states/state-2/prior-disposition.md`, copied once before execution;
- `independent-local-review-state1.md`;
- `evidence/state-1/source-manifest.json`, `receipt.json`, and `summary.json`;
- `states/state-2/authorization.json`.

The new declaration and second-state constructor are not created merely by preparing this guard.
After independent review and explicit main-task clearance, their final bytes can be pinned and
the guard reviewed once more before capture. Pure prerequisite tests use synthetic text and
do not import or construct a second-state shape. The maximum remains two material states.
