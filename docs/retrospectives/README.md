# Retrospectives

Short retrospectives record what a milestone closeout taught the project. They are not architecture
decisions, implementation plans, or historical rules. A provisional retrospective may be added
before release only when its status is explicitly `release-pending`; it does not make the milestone
complete.

Each retrospective records:

- what took longer or required unexpected iteration;
- what was deliberately cut or deferred;
- the next milestone's visible proof.
