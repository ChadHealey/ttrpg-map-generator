# Retrospectives

Short retrospectives record what a completed milestone taught the project. They
are not architecture decisions, implementation plans, or historical rules.

Each retrospective records:

- what took longer or required unexpected iteration;
- what was deliberately cut or deferred;
- the next milestone's visible proof.
